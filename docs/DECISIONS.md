# GiveMeJob! — зафиксированные продуктовые решения

Дата фиксации: 29 июля 2026 года.

Статус: **принято**. Изменения этих решений требуют отдельной записи в этом
файле и явной корректировки конфигурации.

## 1. Рынок MVP

- Стратегия: **remote-first**.
- География: удалённые вакансии глобально плюс вакансии рынка СНГ.
- Вертикаль: **IT/digital**.
- На фазе 1 источники, запросы и метрики качества ограничиваются этим рынком.

Под «remote-first глобально + СНГ» понимается:

1. Глобальные вакансии включаются, если они допускают удалённую работу.
2. Для стран СНГ дополнительно допускаются релевантные onsite/hybrid-вакансии.
3. Расширение на другие локальные рынки не входит в MVP.

## 2. Язык и индекс

- Основной язык UI: **русский**.
- Все пользовательские строки проходят через i18n-слой; текст не считается
  привязанным к русскому языку на уровне компонентов.
- Индекс вакансий мультиязычный.
- Канонические названия скиллов хранятся на английском языке.
- Основная таксономия скиллов: **ESCO**; локальные и языковые варианты
  хранятся как алиасы канонической сущности.

## 3. Модель исходного кода

- Исходный код закрытый.
- GitHub-репозиторий приватный.
- Ключи агрегаторов и LLM-провайдеров хранятся только в переменных окружения,
  GitHub Secrets или серверном secret store.
- Провайдерские ключи не встраиваются в десктопный клиент.

## Машиночитаемый источник

Значения продублированы в [`config/product.json`](../config/product.json).
Переменные окружения в `.env.example` позволяют переопределять только
операционные значения, не меняя принятый продуктовый scope молча.
