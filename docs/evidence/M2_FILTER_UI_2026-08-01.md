# M2 filter/feed/detail UI evidence — 2026-08-01

Статус: локальная инженерная проверка реализованного M2 UI-контракта. Эта
запись не закрывает M2 целиком, не является clean-Windows test и не разрешает
публикацию GitHub Release.

## Реализованный UI-контракт

- Сортировка `relevance/newest/salary` находится только в toolbar выдачи и
  отправляет закрытое enum-значение в `SearchQuery`.
- Remote, seniority, employment и source поддерживают multi-select. Source
  values и counts приходят из `get_filter_options`; несуществующие counts для
  остальных enum не имитируются.
- Skill/location autocomplete используют только локальный IPC, показывают
  популярные значения при пустом query и поддерживают ArrowUp/ArrowDown,
  Home/End, Enter и Escape.
- Suggestions и feed виртуализируются при количестве больше 50.
- Minimum salary принимает только конечное неотрицательное значение не больше
  10 000 000; invalid, negative и NaN не коммитятся. `salaryKnownOnly`
  остаётся отдельным boolean.
- Active chips снимаются по одному. «Сбросить все» очищает filters, сохраняя
  search text и отдельно управляемую сортировку.
- Cursor page загружается через `nextCursor`, добавляется к текущим jobs и не
  повторяет offset pagination.
- Feed показывает company monogram, стабильные location/salary slots и
  выделяет выбранную строку через `aria-current`, accent border/background.
  Шеврон отсутствует; вся строка остаётся одной keyboard-accessible target.
- `j/k` перемещают selection; ArrowUp/ArrowDown работают при фокусе в feed.
- Detail имеет выраженную company/job hierarchy, локализованные enum badges и
  primary original-link action. Source/attribution/snapshot version находятся
  в collapsed technical block.
- Description не интерпретирует HTML или Markdown. React-компонент безопасно
  группирует plain text в paragraphs, bullet lists и отдельный NOTE block с
  шириной текста до `75ch`.
- Видимая snapshot date берётся только из `source_frozen_at` и форматируется
  как локализованная дата. Counts и salary ranges используют единое русское
  форматирование; display-only title/skill normalization не меняет catalog.
- Filters и detail сворачиваются; узкий layout переводит их в overlay panels.
  Semantic design tokens задают light/dark contrast, accent, focus и styled
  scrollbars.

## Что остаётся до закрытия M2

- воспроизводимый feed-scroll замер с проверкой длительных кадров;
- cold first query, repeated startup и steady-state RAM на описанной Windows
  test environment;
- финальный ручной keyboard-only, light/dark и reduced-motion audit;
- фиксация результатов этих проверок отдельным immutable evidence.

Shortlist/save и `s` относятся к M3. Hide и apply automation отсутствуют в
текущем MVP scope. До отдельного контракта UI не создаёт неработающие действия.
